Agents can now install the release wheel, discover its bundled setup and retrieval skills, and
configure workstation document access with only the operator's required missing inputs.

- Package `local-rag-setup` and `local-rag` skills with runtime discovery that works outside a checkout
  and without the virtualenv on PATH. `install-skills` supports custom scopes, read-only checks,
  previews, idempotent installation and explicit managed upgrades while preserving unrelated files.
- Guide setup through existing CLI source/OAuth/indexing commands, reader MCP registration and real
  retrieval verification. Preserve existing choices and authorization; keep credential values out of
  chat. OCR, embeddings and continuous indexing remain opt-in.
- Support protected `credentials/embeddings.json` under the data home for credentials/settings that
  survive CLI, GUI MCP and background-service launches. Environment overrides remain supported.
- Retain native MCP SDK negotiation, structured and text results, correct tool/protocol error
  boundaries and external-interaction annotations for search/indexing.

Validation on 2026-09-13: 87 regression tests on macOS, formatting/lint/types/compile checks, wheel
and sdist verification, and clean-wheel installation outside the checkout. Independent verification
covered real SDK search/read/provenance under modern `2026-07-28` discovery and legacy `2025-11-25`
initialization, installer lifecycle/path spaces, durable background indexing, and fresh-process
semantic retrieval using protected-file credentials against an authenticated loopback fixture.
Publication additionally requires successful CI on the exact marked main commit, including Python
3.11–3.13 quality checks and clean-wheel/skill/MCP verification on macOS and Linux.

Live Google OAuth, downloaded OCR/local models and production embedding endpoints were not used in
this validation. The release does not imply certification of every MCP client or optional extension.

### Install or upgrade

Install `phamviet_local_rag_mcp-0.9.0-py3-none-any.whl` from this release in the intended dedicated
environment and verify `SHA256SUMS`. Then run the installed executable's `install-skills`, or
`install-skills --replace --dest EXISTING_SKILLS_ROOT` to update previously managed skills. Read the
reported setup skill and reconnect the client when needed. Do not rerun initialization over existing
settings merely to reconnect MCP. No database migration or source-file changes are required for
this upgrade; retain the same protected data home and existing source registry.

See the [agent installation guide](https://github.com/phamviet86/local-rag-mcp/blob/v0.9.0/README.md#install-with-an-agent)
and [deployment guide](https://github.com/phamviet86/local-rag-mcp/blob/v0.9.0/docs/deployment.md).
The distribution is `phamviet-local-rag-mcp`; the unrelated PyPI package `local-rag-mcp` is not this
project. This GitHub release does not publish to PyPI or upgrade an existing production service.
